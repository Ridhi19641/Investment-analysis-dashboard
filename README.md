# Investment-analysis-dashboard
Excel-based investment behavior analysis dashboard using pivot tables, slicers, correlation analysis, and data visualization.

## Project Overview

This project analyzes participant investment behavior using Excel.

The analysis focuses on:

- Investment avenues
- Savings objectives
- Investment duration
- Expected returns
- Information sources
- Correlation analysis

The project includes data cleaning, pivot tables, dashboard creation, and interactive visualizations.

---

## Tools Used

- Microsoft Excel / WPS Spreadsheet
- Pivot Tables
- Pivot Charts
- Slicers
- VLOOKUP
- Correlation Analysis
- Dashboard Design

---

## Key Findings

### Investment Preferences
- Mutual Funds were the most preferred investment avenue.
- Fixed Deposits and Equity were also popular choices.

### Savings Objectives
- Retirement planning was the dominant objective.
- Healthcare and education were secondary objectives.

### Correlation Analysis
- Age vs Investment Duration: 0.05 (Very Weak Positive)
- Duration vs Expected Returns: 0.26 (Weak Positive)
